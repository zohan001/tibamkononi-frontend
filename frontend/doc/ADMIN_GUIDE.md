# Tibamkononi Administrator Guide

## Introduction

This guide is intended for hospital administrators responsible for
managing the Tibamkononi platform within their facility.

## Administrator Responsibilities

-   Manage hospital profile
-   Manage user accounts
-   Monitor operations
-   Review reports
-   Oversee inventory
-   Configure departments and wards
-   Ensure data security

## Logging In

Administrators authenticate using their assigned credentials and should
use strong passwords with multi-factor authentication where available.

## Hospital Configuration

Administrators can: - Update hospital details - Configure departments -
Add buildings and wards - Define bed capacities - Maintain contact
information

## User Management

Create and manage accounts for: - Doctors - Nurses - Pharmacists -
Laboratory staff - Receptionists - Administrators

Recommended practices: - Assign least-privilege roles. - Disable
inactive accounts promptly. - Review permissions regularly.

## Patient Oversight

Administrators can: - Search patient records - Audit registrations -
Monitor admissions and discharges - Review service utilization

## Inventory Management

Monitor: - Current stock levels - Low-stock alerts - Expiring
medicines - Supplier information - Stock movement history

## Staff Management

-   Review attendance
-   Monitor staffing levels
-   Track departmental assignments

## Reports & Analytics

Generate and review: - Daily reports - Monthly summaries - Inventory
reports - Bed occupancy - Staff attendance - Operational KPIs

## AI Dashboard

Gemma AI provides: - Operational summaries - Inventory insights -
Clinical support summaries - Emergency prioritization assistance

Administrators should use AI recommendations to support---not
replace---operational decision-making.

## Security

-   Use strong passwords.
-   Keep credentials confidential.
-   Log out of shared devices.
-   Review audit logs regularly.
-   Back up critical data.

## Backup & Recovery

-   Schedule routine database backups.
-   Test restoration procedures.
-   Document recovery processes.

## Troubleshooting

Common issues: - Login failures - Network connectivity - Database
connectivity - Permission errors - Missing data

Consult system logs before escalating issues.

## Best Practices

-   Review dashboards daily.
-   Respond to critical alerts promptly.
-   Maintain accurate inventory.
-   Keep staff records current.
-   Apply software updates regularly.
