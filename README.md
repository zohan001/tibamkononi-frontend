# Tibamkononi

## Overview

Tibamkononi is an AI-powered healthcare management platform for
hospitals, integrating patient management, AI-assisted triage, emergency
response, inventory, appointments, reporting, and analytics.

## Features

-   Multi-hospital support
-   Electronic Medical Records
-   AI-assisted diagnosis support
-   Inventory management
-   Staff management
-   Bed management
-   Appointment scheduling
-   Emergency response
-   Reporting dashboards

## Tech Stack

-   Next.js
-   TypeScript
-   Tailwind CSS
-   Node.js
-   Express
-   MongoDB
-   Gemma AI
